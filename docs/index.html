اولین اسکریپت شروع
اتصال به API و ارسال پیام
from gitbin import Bot

# اتصال به ربات
bot = Bot(token="YOUR_BOT_TOKEN")

# اطلاعات ربات
me = bot.get_me()
print(me["first_name"])   # نام ربات

# ارسال پیام
bot.send_message(
    chat_id=123456789,
    text="سلام 👋"
)
دریافت آپدیت‌ها Long Polling
پایه ساخت هر ربات — دریافت پیام‌های جدید
from gitbin import Bot

bot = Bot(token="YOUR_BOT_TOKEN")
bot.delete_webhook()   # قبل از getUpdates لازمه

offset = 0
while True:
    updates = bot.get_updates(offset=offset, timeout=25)
    for upd in updates or []:
        offset = upd["update_id"] + 1
        if "message" in upd:
            msg = upd["message"]
            bot.send_message(msg["chat"]["id"], f"🔁 {msg.get('text', '')}")

getUpdates✅
دریافت آپدیت‌ها با Long Polling

پارامترها

نامنوعالزامیتوضیح
offsetint—آخرین update_id + 1
limitint—حداکثر ۱۰۰
timeoutint—۰ تا ۵۰ ثانیه
allowed_updateslist—فیلتر نوع آپدیت
updates = bot.get_updates(offset=0, timeout=25)
for upd in updates or []:
    print(upd["update_id"])

🔹 ارسال پیام ۳ متد

sendMessage✅
ارسال پیام متنی — پشتیبانی از HTML، Markdown، دکمه شیشه‌ای

پارامترها

نامنوعالزامیتوضیح
chat_idint✔شناسه چت
textstr✔متن (حداکثر ۴۰۹۶)
parse_modestr—HTML / Markdown
reply_markupdict—دکمه شیشه‌ای

    chat_id=123,
    text="سلام 👋",

            [{"text": "❌ خیر", "callback_data": "no"}],

    }
)

🔹 خطاها مدیریت حرفه‌ای

✅ هر description یک Exception اختصاصی داره.

💡 می‌تونی دقیقاً بگیری چه خطایی رخ داده.

try/exceptمثال
from gitbin import Bot, GitbinError
from gitbin.errors import ChatIdInvalid, BalanceTooLow

try:
    bot.send_message(chat_id="bad", text="x")
except ChatIdInvalid as e:
    print("چت نامعتبر:", e)
except BalanceTooLow as e:
    print("موجودی کم:", e)
except GitbinError as e:
    print(f"خطای دیگر: {e.code} {e.description}")
لیست خطاها۲۰+
Exceptiondescriptionمعنی
ChatIdInvalidCHAT_ID_INVALIDچت نامعتبر
UserIdInvalidUSER_ID_INVALIDکاربر نامعتبر
FileIdInvalidFILE_ID_INVALIDفایل نامعتبر
MethodNotFoundMETHOD_NOT_FOUNDمتد وجود ندارد
AccessTokenInvalidACCESS_TOKEN_INVALIDتوکن نامعتبر
BalanceTooLowBALANCE_TOO_LOWموجودی کم
EphemeralTargetRequiredEPHEMERAL_TARGET_REQUIREDreceiver_user_id لازم
FileTooBigFILE_TOO_BIGفایل بزرگ‌تر از ۲۵MB
ConflictErrorCONFLICTدرخواست تکراری
