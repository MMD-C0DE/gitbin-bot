🚀 نصب و شروع ۳ قدم

🔗 PyPI: pip install gitbin-bot

🐍 پایتون: 3.8 یا بالاتر

📦 وابستگی: فقط requests

pip install سریع
نصب از PyPI
# نصب pip install gitbin-bot # تست python -c "from gitbin import Bot; print('ok')"
اولین اسکریپت شروع
اتصال به API و ارسال پیام
from gitbin import Bot bot = Bot(token="YOUR_BOT_TOKEN") # اطلاعات ربات me = bot.get_me() print(me["first_name"]) # ارسال پیام bot.send_message(chat_id=123456789, text="سلام 👋") # موجودی استارز bal = bot.get_my_star_balance() print(f"{bal['amount']:,} استارز")

🔹 هویت و آپدیت ۶ متد

getMe ✅
اطلاعات ربات (آیدی، نام، یوزرنیم) — برای تست اتصال و توکن
me = bot.get_me() # {"id": 123, "is_bot": true, "first_name": "ربات", "username": "my_bot"}
getUpdates ✅
دریافت آپدیت‌ها با Long Polling

پارامترها

نامنوعالزامیتوضیح
offsetint—آخرین update_id + 1
limitint—حداکثر ۱۰۰
timeoutint—۰ تا ۵۰ ثانیه
allowed_updateslist—فیلتر نوع آپدیت
getFile ✅
گرفتن مسیر دانلود فایل بر اساس file_id
r = bot.get_file(file_id="BQACAgIAAxkB...") print(r["file_path"]) # دانلود از: https://api.gitbin.site/file/botTOKEN/{file_path}
setWebhook ✅
تنظیم آدرس سرور برای دریافت مستقیم آپدیت‌ها (HTTPS)
deleteWebhook ✅
حذف webhook — قبل از استفاده از getUpdates لازمه
getWebhookInfo ✅
وضعیت webhook فعلی

🔹 ارسال پیام ۳ متد

sendMessage ✅
ارسال پیام متنی — پشتیبانی از HTML، Markdown، دکمه شیشه‌ای

پارامترها

نامنوعالزامیتوضیح
chat_idint✔شناسه چت
textstr✔متن (حداکثر ۴۰۹۶)
parse_modestr—HTML / Markdown
reply_markupdict—دکمه شیشه‌ای
reply_to_message_idint—ریپلای به پیام
bot.send_message( chat_id=123, text="سلام 👋", parse_mode="HTML", reply_markup={ "inline_keyboard": [ [{"text": "✅ بله", "callback_data": "yes"}], [{"text": "❌ خیر", "callback_data": "no"}], ] } )

ارسال تاس/بسکتبال/فوتبال/... — عدد توسط سرور تعیین می‌شه

ایموجی‌های پشتیبانی‌شده

🔹 خطاها مدیریت حرفه‌ای

✅ هر description یک Exception اختصاصی داره.

💡 می‌تونی دقیقاً بگیری چه خطایی رخ داده.

try/exceptمثال
from gitbin import Bot, GitbinError from gitbin.errors import ChatIdInvalid, BalanceTooLow try: bot.send_message(chat_id="bad", text="x") except ChatIdInvalid as e: print("چت نامعتبر:", e) except BalanceTooLow as e: print("موجودی کم:", e) except GitbinError as e: print(f"خطای دیگر: {e.code} {e.description}")
لیست خطاها۲۰+
Exceptiondescriptionمعنی
ChatIdInvalidCHAT_ID_INVALIDچت نامعتبر
UserIdInvalidUSER_ID_INVALIDکاربر نامعتبر
FileIdInvalidFILE_ID_INVALIDفایل نامعتبر
MethodNotFoundMETHOD_NOT_FOUNDمتد وجود ندارد
AccessTokenInvalidACCESS_TOKEN_INVALIDتوکن نامعتبر
BalanceTooLowBALANCE_TOO_LOWموجودی کم
EphemeralTargetRequiredEPHEMERAL_TARGET_REQUIREDreceiver_user_id لازم
FileTooBigFILE_TOO_BIGفایل بزرگ‌تر از ۲۵MB
ConflictErrorCONFLICTدرخواست تکراری
